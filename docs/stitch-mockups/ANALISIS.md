# Analisis de vistas para Stitch

Estos HTML son mockups estaticos derivados de las rutas y componentes Angular actuales. Cada archivo incluye CSS embebido para poder abrirse o entregarse de forma independiente.

## Login

- `00-login.html`: pantalla de acceso tipo lobby, marca MIND-SPHERE, dialogo de GARY, formulario, credenciales demo y estadisticas de servidor.

## Estudiante

- `01-student-onboarding.html`: creacion de personaje con pasos Briefing, Heroe y Nickname.
- `02-student-groups.html`: home del estudiante en estado de seleccion de grupos inscritos.
- `03-student-tasks.html`: home del estudiante en estado de tareas/misiones del grupo seleccionado.
- `04-student-mission.html`: mision clinica gamificada con HUD, mapa mental, zonas, personaje y briefing.

## Docente

- `05-teacher-overview.html`: dashboard del profesor con metricas, actividad reciente y accesos rapidos.
- `06-teacher-cases.html`: laboratorio de casos psicologicos con tarjetas de estado, acciones y metadata.
- `07-teacher-case-editor.html`: constructor de caso por pestanas, formulario principal y estado del flujo.
- `08-teacher-groups.html`: gestion de grupos, formulario y listado de estudiantes asociados.
- `09-teacher-students.html`: gestion de estudiantes, asignacion a grupos y tabla de progreso.
- `10-teacher-tasks.html`: constructor de tareas por checklist de caso, escenarios y preguntas.
- `11-teacher-results.html`: telemetria de resultados con metricas y tabla por estudiante/tarea.

## Administrador

- `12-admin-dashboard.html`: command center con metricas globales, nodos, licencias, reportes y logs.
- `13-admin-users.html`: gestion de usuarios y permisos, docente/estudiante, flag creador de casos.
- `14-admin-licenses.html`: control de licencias, vencimientos y vales de acceso.
- `15-admin-reports.html`: reportes institucionales de sesiones, eficiencia y estado.
- `16-admin-logs.html`: auditoria y logs del sistema.
- `17-admin-help.html`: ayuda con referencias de documentacion y reglas REQ-01/REQ-02.
